# Note

>A simple React + Vite note-taking app for creating, viewing, and deleting short notes with a cleansticky-note   inspired interface.

## Features

- Add notes with a title and detailed content
- Delete notes instantly from the card
- Responsive layout for desktop and smaller screens
- Modern dark theme with a card-based UI
- Built with React and Vite for a fast frontend experience

## Tech Stack

- React 19
- Vite
- JavaScript
- Tailwind CSS
- Lucide React icons

## Usage

- Enter a note heading in the first input field.
- Add the note details in the text area.
- Click "Add Note" to save it.
- Use the delete icon on a note card to remove it.
